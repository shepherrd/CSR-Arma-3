# UI assets — CSR 0.6.1

- `cascadia_co.paa`: mountain/forest banner generated with the built-in image-generation tool on 2026-09-28. Converted to a 2048 x 512 engine texture with Bohemia ImageToPAA. The source photograph remains in the project workspace at `work/csr-banner-original.png`.
- `pine_ca.paa`: original simple pine silhouette, constructed from vector-style polygons and converted to a 128 x 128 transparent PAA. It is a UI motif inspired by the provided reference, not a claim to reproduce an official insignia.

## Generation prompt

Use case: photorealistic-natural. Asset type: background banner texture for an in-game Cascadian armed forces personnel portal. Create a wide panoramic photograph of rugged Pacific Northwest snow-streaked mountains behind layered evergreen conifer forest and low atmospheric mist. Subdued dark spruce green, blue grey and silver palette, overcast natural light, serious quiet editorial landscape. Broad mountain ridge across upper middle, dense dark forest across bottom. Darker calm left third for white overlay text. Wide horizontal 3:1 composition, no people, buildings, flags, logos, symbols, lettering, UI, borders or text of any kind. This is only the photographic landscape backdrop, not a website mockup.

No generated text is baked into the banner. All UI labels and personnel data are native Arma controls.
